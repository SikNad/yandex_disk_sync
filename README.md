# Сервис синхронизации файлов с Яндекс.Диском

## Описание
Программа для фоновой синхронизации указанной локальной папки с облачным хранилищем Яндекс.Диск. Программа отслеживает появление новых файлов, их изменение и удаление, автоматически внося соответствующие изменения в облако.

## Стек технологий
* Python 3.10
* `requests` (для работы с API Яндекс.Диска)
* `configparser`, `os`, `logging` (стандартная библиотека)
